# Alice Homebrew 0.7.0

Плагинам больше не нужен root, чтобы реагировать на кнопки, датчик и музыку.

- WASM API 3: разрешения `input.buttons`, `sensor.proximity` и `audio.levels` дают песочнице данные колонки только на чтение; `assistant.state` сообщает, слушает или говорит Алиса (без слов); без разрешений доступны время UTC (`utc_time`) и случайные числа (`random_u32`). Описание — в docs/PLUGIN_GUIDE.md, заголовок — sdk/wasm/alice.h, примеры — examples/sound-ring и examples/ring-clock.
- Кнопки и датчик читаются без перехвата: Алиса работает как раньше, датчик менеджер не включает. Микрофон плагинам недоступен.
- Плагины API 3 публикуются в новом `catalog/v3.json`. Старые менеджеры читают `v1`/`v2` и их не видят; новый менеджер берёт `v3.json`, а без него — `v2.json`.
- Подтверждение кнопкой из 0.6.1 теперь использует тот же общий обработчик кнопок.
- Второй встроенный источник — каталог форка provincialcxz со своим закреплённым ключом, рядом с каталогом автора. В нём «Звуковое кольцо» и «Часы на кольце» (API 3, без root). Источник можно отключить или удалить в настройках; удалённый не возвращается. Подробнее: docs/FORK_CATALOG.md.
- Вход по коду доступа переживает перезапуск и автообновление менеджера. В `sessions.json` лежат только хэши сессий; смена кода сбрасывает все входы.
- Менеджер занимает порт до запуска плагинов: если порт занят, служба сразу завершается и не оставляет работающих нативных плагинов.
- «Проверить сейчас» сообщает, если проверка обновлений уже идёт.
- Магазин модератора: одновременная отправка одного и того же пакета больше не создаёт две заявки; обрыв соединения не превращает сканирование в `scanner_error`.
- `pack` и `export` удаляют недописанный файл при ошибке записи.
- Spotify Connect 2.0.0-beta.1 (plugins/spotify): официальный Spotify Soloist вместо librespot. Колонка сама скачивает Soloist у Spotify и обновляет его до истечения 90 дней. Он работает на встроенном glibc 2.41, а звук отдаёт через свою заглушку libpulse в штатный микшер Алисы; музыка плавно приглушается, пока Алиса слушает или отвечает. Нужны Spotify Premium и свой API-ключ Soloist. Для ключа в настройках новый тип поля `secret`: значение не возвращается в браузер. Собирается в CI (`.github/workflows/spotify.yml`); на колонке ещё не проверялся.
- В настройках менеджера — «Диагностика кнопок и датчика»: живые нажатия и показания датчика для проверки на колонке.
- Общий вывод звука и измеритель уровней AirPlay вынесены в plugins/internal/sharedaudio и используются обоими плагинами.
- SSH 1.0.0-beta.2: понятнее описан адрес прослушивания (вся сеть, вход только по ключу).

На физической колонке не проверялось. Порядок проверки — docs/DEVICE_TEST_PLAN.md.

# Alice Homebrew 0.6.1

Подтверждение кнопкой на колонке перед запуском кода с полным root. По умолчанию выключено.

- С флагом `--button-confirm` включение нативного плагина и обновление уже включённого нативного плагина ждут нажатия любой кнопки на колонке (30 секунд). Другое устройство в сети не сможет получить root без физического доступа.
- Пока менеджер ждёт, кольцо мигает янтарным (если его не занимает плагин), а страница показывает подсказку. Без нажатия ничего не меняется.
- Нажатие подтверждает только уже ожидающее действие; два действия одновременно не ждут.
- Кнопки читаются без перехвата: Алиса получает нажатие как обычно (например, громкость сдвинется на одно деление).
- Включение на колонке: `touch /data/alice-homebrew/button-confirm.enabled`, затем `/data/alice-homebrew/start.sh stop` и `start`.

На физической колонке не проверялось: нужен отзыв, приходят ли события `adc_keypad` на вашей прошивке.

# Alice Homebrew 0.6.0

Сборка форка provincialcxz/alice-homebrew на основе 0.5.4. Исправления безопасности веб-менеджера.

- Защита от DNS rebinding: менеджер отвечает только на обращения по IP-адресу, `localhost` или имени `*.local`. Своё имя из роутера можно разрешить флагом `--allowed-host`.
- Пакеты обрабатываются по одному: параллельные загрузки получают ответ 503, а не исчерпывают память колонки.
- Необязательный код доступа для колонки: `--access-code` (или галочка в Station Mini Root).
- В cookie хранится случайный ID сессии, а не сам код; «Выйти» завершает сессию на сервере.
- Ограничение попыток входа больше не сбрасывается целиком при переполнении, IPv6-адреса считаются по подсети /64.
- Автообновление менеджера получает релизы из provincialcxz/alice-homebrew.
