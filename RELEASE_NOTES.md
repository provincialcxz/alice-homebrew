# Alice Homebrew 0.6.0

Сборка форка provincialcxz/alice-homebrew на основе 0.5.4. Исправления безопасности веб-менеджера.

- Защита от DNS rebinding: менеджер отвечает только на обращения по IP-адресу, `localhost` или имени `*.local`. Раньше любой сайт, открытый в браузере в той же сети, мог установить и включить нативный плагин с полным root. Своё имя из роутера можно разрешить флагом `--allowed-host`.
- Пакеты обрабатываются по одному: параллельные загрузки получают ответ 503, а не исчерпывают память колонки (лимит 64 МиБ). Слишком большое тело запроса — 413.
- Необязательный код доступа для колонки: `--access-code` (или галочка в Station Mini Root). По умолчанию вход по-прежнему не нужен.
- В cookie хранится случайный ID сессии, а не сам код; «Выйти» завершает сессию на сервере.
- Ограничение попыток входа больше не сбрасывается целиком при переполнении, IPv6-адреса считаются по подсети /64.
- Автообновление менеджера теперь получает релизы из provincialcxz/alice-homebrew.

Переход с официальной сборки: Station Mini Root → «Обновить только Homebrew (ADB root)». Плагины и их настройки сохраняются. Прямой установки на физическую колонку при подготовке выпуска не выполнялось.
