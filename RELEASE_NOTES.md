# Alice Homebrew 0.6.1

Подтверждение кнопкой на колонке перед запуском кода с полным root. По умолчанию выключено.

- С флагом `--button-confirm` включение нативного плагина и обновление уже включённого нативного плагина ждут нажатия любой кнопки на колонке (30 секунд). Другое устройство в сети не сможет получить root без физического доступа.
- Пока менеджер ждёт, кольцо мигает янтарным (если его не занимает плагин), а страница показывает подсказку. Без нажатия ничего не меняется.
- Нажатие подтверждает только уже ожидающее действие; два действия одновременно не ждут.
- Кнопки читаются без перехвата: Алиса получает нажатие как обычно (например, громкость сдвинется на одно деление).
- Включение на колонке: `touch /data/alice-homebrew/button-confirm.enabled`, затем `/data/alice-homebrew/start.sh stop` и `start`.

На физической колонке не проверялось: нужен отзыв, приходят ли события `adc_keypad` на вашей прошивке.

# Alice Homebrew 0.6.0

Сборка форка provincialcxz/alice-homebrew на основе 0.5.4. Исправления безопасности веб-менеджера.

- Защита от DNS rebinding: менеджер отвечает только на обращения по IP-адресу, `localhost` или имени `*.local`. Своё имя из роутера можно разрешить флагом `--allowed-host`.
- Пакеты обрабатываются по одному: параллельные загрузки получают ответ 503, а не исчерпывают память колонки.
- Необязательный код доступа для колонки: `--access-code` (или галочка в Station Mini Root).
- В cookie хранится случайный ID сессии, а не сам код; «Выйти» завершает сессию на сервере.
- Ограничение попыток входа больше не сбрасывается целиком при переполнении, IPv6-адреса считаются по подсети /64.
- Автообновление менеджера получает релизы из provincialcxz/alice-homebrew.
