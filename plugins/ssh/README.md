# SSH для Alice Homebrew

Версия `1.0.0-beta.2`. Терминал SSH, выполнение команд и SFTP для Яндекс Станции Мини 1, YNDX-0004, Linux ARM64 с ADB root и Homebrew API 2.

**По просьбе владельца выпуск собран и опубликован без тестов и без установки на колонку. Работоспособность подключения, PTY и SFTP на устройстве пока не подтверждена.**

## Настройка

1. Установите SSH из официального магазина Homebrew и откройте настройки плагина.
2. На своём компьютере создайте ключ командой `ssh-keygen -t ed25519` либо используйте имеющийся ключ OpenSSH.
3. Скопируйте одну строку **публичного** ключа из файла `.pub` в поле «Ваш публичный SSH-ключ». Например, строку из `~/.ssh/id_ed25519.pub`. Личный ключ остаётся на компьютере.
4. Оставьте порт `2222` или задайте свой, сохраните настройки и включите плагин.
5. Подключитесь: `ssh -p 2222 root@IP-КОЛОНКИ`. При нестандартном пути к ключу добавьте `-i ПУТЬ-К-ЛИЧНОМУ-КЛЮЧУ`.

Для файлов: `sftp -P 2222 root@IP-КОЛОНКИ`. В WinSCP выберите протокол SFTP, IP колонки, порт 2222, пользователя root и свой личный ключ. Пароль и вход без ключа не предусмотрены. Публичные сертификаты SSH и параметры authorized_keys перед ключом в этой версии не поддерживаются: вставляйте обычную строку публичного ключа.

Рабочая папка терминала и SFTP — `/data`. После входа доступны все файлы и команды с правами root; это не изолированный пользовательский каталог. Перенаправление портов, agent forwarding и X11 forwarding не реализованы.

## Параметры

- Порт: 1–65535, по умолчанию 2222. Можно выбрать стандартный 22, если он свободен.
- Публичный ключ: одна строка OpenSSH до 1024 символов. До её заполнения плагин не запускает SSH-сервер.
- Адрес: вся локальная сеть (`0.0.0.0`, по умолчанию) или только сама колонка (`127.0.0.1`, подключение через `adb forward tcp:2222 tcp:2222`). Порт открыт всем в сети, но войти можно только по вашему ключу; в гостевых и публичных Wi-Fi выбирайте `127.0.0.1`.
- Одновременные сеансы: 1–4, по умолчанию 2; терминал, команда и SFTP занимают по одному сеансу. Одновременно разрешено до четырёх SSH-соединений, ожидание авторизации ограничено 15 секундами.
- SFTP: можно выключить отдельно от терминала.

Ключ сервера Ed25519 создаётся на колонке при первом корректно настроенном запуске, хранится с правами 0600 в данных плагина и не меняется при обновлениях. Его SHA-256 fingerprint показывается в журнале плагина. Сам ключ в пакет и каталог не входит. Удаление плагина удаляет и его ключ сервера; после переустановки fingerprint изменится.

Выключение плагина закрывает SSH-соединения и управляемые сеансы. Конфигурация звука, голосовые службы Алисы и ADB не изменяются.

## Сборка и исходники

Нужен Go 1.26.5 или совместимый более новый Go. Выполните `go mod download`, затем `python3 build-plugin.py` в этой папке. Сценарий только компилирует и упаковывает Linux ARM64, не запускает тесты и не обращается к колонке. В архиве исходников релиза есть vendor/ для сборки без загрузки модулей: `GOOS=linux GOARCH=arm64 CGO_ENABLED=0 go build -mod=vendor -trimpath -ldflags='-s -w' -o plugin.elf ./service`.

Точные версии зависимостей и контрольные суммы записаны в `go.mod` / `go.sum`. SSH реализован на [golang.org/x/crypto/ssh](https://pkg.go.dev/golang.org/x/crypto/ssh), SFTP — [github.com/pkg/sftp](https://github.com/pkg/sftp), PTY использует Linux API через golang.org/x/sys/unix.
