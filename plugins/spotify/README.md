# Spotify Connect для Alice Homebrew

Версия `1.0.0-beta.1`. Приёмник Spotify Connect для Яндекс Станции Мини 1, YNDX-0004, на основе [librespot 0.8.0](https://github.com/librespot-org/librespot/tree/v0.8.0). Нужны Homebrew 0.7.0 или новее, готовый ADB root и **Spotify Premium**.

**Выпуск собран без установки на колонку. Подключение и звук на устройстве пока не подтверждены.**

## Как пользоваться

1. Установите плагин из каталога provincialcxz в Homebrew, при желании задайте имя и качество, сохраните и включите.
2. Телефон или компьютер со Spotify должен быть в той же сети, что и колонка, без изоляции клиентов Wi-Fi.
3. В Spotify нажмите значок устройств и выберите `Alice Mini` (или ваше имя). Первое подключение передаёт вход колонке; он сохраняется в данных плагина и переживает перезапуск.

Звук идёт через штатный `aplay` и микшер `dmixer` Алисы, как у AirPlay: Алиса продолжает слышать и отвечать, а музыка не забирает звуковую карту. Пока играет Spotify, данные о звуке доступны плагинам с разрешением `audio.levels` (например, «Звуковое кольцо»). Музыка на колонке не кэшируется, чтобы не занимать память.

## Известные ограничения

- **Часть новых аккаунтов Spotify может не воспроизводить треки** с ошибкой `audio key error` в журнале. Это открытая проблема самого librespot ([librespot#1649](https://github.com/librespot-org/librespot/issues/1649)), не связанная с колонкой. Обходы через сторонние декодеры защиты Spotify в плагин сознательно не включены: есть сообщения о блокировке аккаунтов за их использование.
- Громкость Spotify пока программная и не связана с громкостью Алисы. Приглушения музыки на время ответа Алисы ещё нет.
- librespot — неофициальный клиент. Используйте его на свой риск и в соответствии с правилами Spotify.

## Настройки

| Поле | Значение |
| --- | --- |
| Имя в Spotify | Как колонка называется в списке устройств, до 32 символов |
| Качество звука | 96, 160 или 320 кбит/с |
| Громкость при подключении | Начальная громкость Spotify, 0–100 % |
| Выравнивать громкость | Нормализация громкости librespot |
| Порт обнаружения | TCP-порт Zeroconf, по умолчанию 4070 |

## Сборка

Нужен Linux с rustup, `cargo-zigbuild` 0.23.4 и zig 0.15.1 (так собирает CI, `.github/workflows/spotify.yml`):

```bash
bash plugins/spotify/build-receiver.sh
python3 plugins/spotify/build-plugin.py
```

`build-receiver.sh` скачивает исходник librespot 0.8.0 с crates.io, сверяет SHA-256 и собирает статический `aarch64-unknown-linux-musl` с `--locked`, без OpenSSL, ALSA и Avahi. Лицензии librespot и всех Rust-зависимостей записываются в `licenses/`.
